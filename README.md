# あまやどりの町 — Rainy Day Quest

雨が降りつづく港町を舞台にした、スマホのブラウザで遊べる 3D アクション RPG です。

**▶ プレイ: https://bubbleshaker.github.io/rainy-day-rpg/**

## ストーリー

港町アマヤドでは、もう百日も雨が止みません。
丘の上の祠に住む「雨の精霊」が、ずっと泣きつづけているのです。
町の長老によると、精霊の涙を止めるには「晴れのかけら」が 3 つ必要だとか。
傘を手に、しずくの森・カエル沼・港の岬へ向かいましょう。

## 操作

| 操作 | スマホ | PC |
| --- | --- | --- |
| 移動 | 画面の左側をドラッグ | WASD / 矢印キー |
| 視点 | 画面の右側をドラッグ | マウスでドラッグ |
| 攻撃（3 段コンボ） | 攻撃ボタン（長押しで連続攻撃） | クリック / J |
| 回避 | 回避ボタン | Space |
| スピン（周りの敵をまとめて攻撃） | スピンボタン | K |
| ココア（HP 回復） | ココアボタン | Q |
| 話す / 会話を送る | 話すボタン / 画面タップ | E / Enter |

- 敵の体がチカチカ光ったら攻撃の合図です。回避でよけましょう。
- 広場の傘屋に話しかけると HP が全回復します。
- 進行状況はブラウザに自動で保存されます（タイトル画面の「つづきから」）。

## 技術メモ

- [three.js](https://threejs.org/) を CDN（importmap）から読み込むだけの静的サイトです。ビルド不要。
- 雨粒・波紋・稲光・晴れ上がり・虹などの天気表現は `src/rain.js`。
- 雨音・雷・BGM・効果音はすべて Web Audio API で生成しています（音声ファイルなし）。
- ローカルで遊ぶ場合: `python3 -m http.server` を実行して http://localhost:8000/ を開きます。
